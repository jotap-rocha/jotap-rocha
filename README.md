## 🚀 Projetos em destaque

**[`uber-eats-case`](https://github.com/jotap-rocha/uber-eats-case)** *(em evolução)*
Pipeline de dados completo sobre dados gerados artificialmente com a lógica de negócio de um app de delivery. Ingestão em camada raw/Bronze, tratamento em Silver e enriquecimento/disponibilização em Gold (arquitetura Medalhão). Primeira versão 100% batch; evolução em andamento contempla múltiplos sistemas de origem, 3 nuvens distintas e 3 arquiteturas de solução diferentes (Warehouse, Lakehouse, Kappa).

**[`Previsão-Diaria-Rio-de-Janeiro-Airbnb`](https://github.com/jotap-rocha/Previsao-Diaria-Rio-de-Janeiro-Airbnb)**
Previsão do valor de aluguel de imóveis no Airbnb-RJ. Cobre análise exploratória, análise multivariada e correlacional, feature engineering, modelagem preditiva, validação e tuning de modelo, com apresentação final em Streamlit.
